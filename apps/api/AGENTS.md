# apps/api

The single deployed Worker. `src/index.ts` exports `fetch`, `scheduled` and `queue`; `src/workers/MailBeeWorker.ts` builds the Hono/Chanfana app.

## Route groups

- `/user/*` — behind Cloudflare Access (`MiddlewareHandlers.userAuthentication()`), keyed rate limit. Reads identity via `IUserRoute.getAuthenticatedUser(c)`.
- `/api/oauth2/callback/:applicationId` — public, rate-limited by IP, protected by hashed state + PKCE.
- `/api/webhooks/*` — public, secret-checked, not rate-limited (provider retries are legitimate bursts).

Add routes to `src/endpoints/routeTable.ts` and register their request schemas in `packages/shared/src/schema/input.ts`; `validateRequestInput` fails closed when a route has no schema.

The SPA shell comes from `src/generated/spa-shell.ts` (generated by `pnpm run build`, stubbed on install). Only paths starting `/user/` serve it; everything else 404s.

`Env` is the generated CloudflareEnv from `wrangler types`. `DEV_AUTH_EMAIL` is local-only and must never be set in a deployed environment.
